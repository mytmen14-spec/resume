# 💾 Как сохранить видео в WebM

## ⚡ Самый простой способ

### 1. Откройте файл в Chrome

Найдите и откройте файл **`dist/index.html`** в браузере **Google Chrome**:

- **Mac:** двойной клик по файлу → откроется в Chrome
- **Windows:** двойной клик по файлу → откроется в Chrome
- **Или:** перетащите файл в окно Chrome

### 2. Нажмите кнопку «💾 Сохранить как WebM»

На стартовом экране нажмите красную кнопку **«💾 Сохранить как WebM»**

### 3. В появившемся окне выберите:

```
┌─────────────────────────────────────────┐
│  Поделиться экраном                      │
│                                         │
│  ● Вкладки  ○ Окна  ○ Область экрана   │
│                                         │
│  ┌─────────────────────────────────┐   │
│  │  📄 [Эта вкладка] ← ВЫБЕРИТЕ!  │   │
│  └─────────────────────────────────┘   │
│                                         │
│  ☑ Поделиться аудио вкладки             │
│                                         │
│         [Отмена]  [Поделиться]          │
└─────────────────────────────────────────┘
```

**Важно:** Выберите вкладку **«Вкладки»** сверху, затем выберите **эту же вкладку** с анимацией, и нажмите **«Поделиться»**

### 4. Дождитесь окончания

Анимация автоматически запустится и будет записываться 40 секунд.

### 5. Получите файл

После окончания файл **`resume-motion-graphics.webm`** автоматически скачается в папку **«Загрузки»**.

## 🎬 Что получится

| Параметр | Значение |
|----------|----------|
| Формат | WebM |
| Разрешение | Размер вашей вкладки |
| Длительность | 40 секунд |
| Качество | Отличное (пиксель в пиксель) |
| Размер | ~5-15 MB |

---

## 🐛 Если не работает

### Проблема: Не появляется окно выбора

**Решение:** Убедитесь, что используете **Google Chrome** (не Safari, не Firefox для этой функции)

### Проблема: Ошибка «NotAllowedError»

**Решение:** Вы отменили выбор. Нажмите кнопку ещё раз и в этот раз выберите вкладку.

### Проблема: Видео чёрное

**Решение:** При выборе вкладки **НЕ ставьте галочку** «Поделиться аудио вкладки» (она не нужна)

## 📋 Пошаговая инструкция с картинками

1. Откройте `dist/index.html` в Chrome
2. Увидите стартовый экран с двумя кнопками
3. Нажмите красную **«💾 Сохранить как WebM»**
4. Появится окно Chrome «Поделиться экраном»
5. Выберите вкладку **«Вкладки»** вверху
6. Кликните на вкладку с анимацией
7. Нажмите **«Поделиться»**
8. Анимация запустится автоматически
9. Через 40 секунд файл скачается

**Готово!** 🎉
