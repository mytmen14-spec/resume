# 🎥 Как сохранить видео в WebM БЕЗ установки

## Быстрый способ (2 минуты)

### 1. Соберите проект

```bash
npm install
npm run build
```

### 2. Откройте собранный файл

После сборки откройте файл `dist/index.html` в браузере **Google Chrome**:

```bash
# macOS
open dist/index.html

# Windows
start dist/index.html

# Linux
xdg-open dist/index.html
```

### 3. Запишите видео

1. Нажмите кнопку **"🎬 Записать видео"** в правом верхнем углу
2. Дождитесь окончания 40-секундной анимации
3. Файл `resume-motion-graphics.webm` автоматически скачается

**Всё! Видео готово.**

---

## 📁 Что находится в папке `dist/`

После `npm run build` папка `dist/` содержит:

```
dist/
├── index.html              # Откройте этот файл в Chrome
└── assets/
    ├── index-*.css         # Стили (уже включены)
    └── index-*.js          # Код + html2canvas (уже включены)
```

**Вам НЕ нужно:**
- ❌ Устанавливать Node.js
- ❌ Устанавливать npm
- ❌ Запускать сервер
- ❌ Устанавливать зависимости

**Вам нужно ТОЛЬКО:**
- ✅ Google Chrome или Firefox
- ✅ Открыть `dist/index.html`
- ✅ Нажать кнопку записи

---

## 🎬 Параметры видео

- **Формат:** WebM (VP9/VP8)
- **Разрешение:** 375×667px (9:16)
- **Длительность:** 40 секунд
- **Качество:** 5 Mbps
- **FPS:** 30
- **Размер:** ~25-30 MB

---

## 🐛 Если не работает

### Проблема: Кнопка не реагирует

**Решение:** Откройте через локальный сервер:

```bash
# Если есть Python
cd dist
python3 -m http.server 8000
# Откройте http://localhost:8000

# Если есть Node.js
cd dist
npx serve
# Откройте http://localhost:3000
```

### Проблема: Видео не скачивается

**Решение:**
1. Проверьте папку "Загрузки"
2. Разрешите загрузки в настройках браузера
3. Попробуйте другой браузер (Chrome/Firefox)

### Проблема: Ошибка CORS

**Решение:** Используйте локальный сервер (см. выше)

## 📋 Пошаговая инструкция с скриншотами

1. **Откройте терминал** в папке проекта
2. **Выполните:** `npm install && npm run build`
3. **Найдите папку** `dist/` в проекте
4. **Откройте** `dist/index.html` в Chrome
5. **Нажмите** кнопку "🎬 Записать видео"
6. **Ждите** 40 секунд
7. **Получите** файл `resume-motion-graphics.webm`

## 💡 Альтернативный способ: Папка `webm-export/`

Если вы хотите отдельную папку с готовыми файлами:

```bash
# После npm run build
mkdir -p webm-export
cp -r dist/* webm-export/
cp webm-export/README.md webm-export/
```

Теперь папка `webm-export/` полностью автономна и может быть перенесена на любой компьютер.
