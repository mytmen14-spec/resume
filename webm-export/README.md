# 💾 Как сохранить видео в WebM

## ✅ Готово! Проблема решена.

Пути в `dist/index.html` теперь относительные, файл будет работать при открытии через `file://`.

## 🚀 Инструкция (3 шага)

### Шаг 1: Откройте файл

Найдите файл **`dist/index.html`** и откройте его в **Google Chrome**:

- **Mac:** двойной клик по файлу
- **Windows:** двойной клик по файлу  
- **Или:** перетащите файл в окно Chrome

### Шаг 2: Нажмите кнопку записи

На стартовом экране нажмите красную кнопку **«💾 Сохранить как WebM»**

### Шаг 3: Выберите вкладку

В появившемся окне Chrome:
1. Выберите вкладку **«Вкладки»** сверху
2. Кликните на **эту же вкладку** с анимацией
3. Нажмите **«Поделиться»**

Через 40 секунд файл **`resume-motion-graphics.webm`** автоматически скачается в папку «Загрузки».

## 🐛 Если не работает

### Проблема: Страница пустая

**Решение:** Убедитесь, что открыли файл из папки **`dist/`**, а не из корня проекта.

### Проблема: Кнопка не реагирует

**Решение:** 
1. Убедитесь, что используете **Google Chrome** (не Safari)
2. Попробуйте обновить страницу (Ctrl+F5)
3. Откройте консоль (F12) и проверьте ошибки

### Проблема: Ошибка «NotAllowedError»

**Решение:** Вы отменили выбор вкладки. Нажмите кнопку ещё раз и выберите вкладку.

### Проблема: Видео чёрное

**Решение:** При выборе вкладки **НЕ ставьте галочку** «Поделиться аудио вкладки»
