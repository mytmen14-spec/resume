# 💾 Сохранение видео в WebM

## Инструкция (2 шага)

### 1. Откройте `index.html` в Chrome

Двойной клик по файлу `index.html` — откроется в Chrome.

### 2. Нажмите «💾 Сохранить как WebM»

На стартовом экране нажмите красную кнопку.

В появившемся окне:
1. Выберите вкладку **«Вкладки»** сверху
2. Кликните на **эту же вкладку** с анимацией
3. Нажмите **«Поделиться»**

Через 40 секунд файл `resume-motion-graphics.webm` скачается в папку «Загрузки».

---

## Требования

- ✅ Google Chrome
- ❌ Не нужен Node.js
- ❌ Не нужен npm
- ❌ Не нужен сервер

---

## Если не работает

- Убедитесь, что используете **Chrome** (не Safari)
- В окне выбора выберите **«Вкладки»** → **«Эта вкладка»**
- Нажмите **«Поделиться»**
