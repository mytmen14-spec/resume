# 🎥 Сохранение видео в WebM — БЕЗ установки зависимостей

## ⚡ Самый быстрый способ (1 минута)

### Для Mac/Linux:

```bash
# 1. Запустите скрипт экспорта
chmod +x export-webm.sh
./export-webm.sh

# 2. Откройте файл в Chrome
open webm-export/index.html

# 3. Нажмите "🎬 Записать видео"
```

### Для Windows:

```cmd
# 1. Запустите скрипт экспорта
export-webm.bat

# 2. Откройте файл в Chrome
start webm-export\index.html

# 3. Нажмите "🎬 Записать видео"
```

---

## 📋 Что происходит?

Скрипт автоматически:
1. ✅ Собирает проект (`npm run build`)
2. ✅ Копирует все файлы в папку `webm-export/`
3. ✅ Создаёт автономную папку, которую можно открыть в браузере

После этого вам **НЕ НУЖНО**:
- ❌ Node.js
- ❌ npm
- ❌ Сервер
- ❌ Интернет (кроме первого открытия)

Вам нужно **ТОЛЬКО**:
- ✅ Google Chrome или Firefox
- ✅ Открыть `webm-export/index.html`
- ✅ Нажать кнопку записи

---

## 🎬 Как записать видео

1. **Откройте** `webm-export/index.html` в Chrome
2. **Нажмите** кнопку **"🎬 Записать видео"** в правом верхнем углу
3. **Дождитесь** окончания 40-секундной анимации
4. **Получите** файл `resume-motion-graphics.webm` в папке "Загрузки"

---

## 🐛 Решение проблем

### Кнопка записи не работает

**Решение 1:** Откройте через локальный сервер:

```bash
# Mac/Linux
cd webm-export
python3 -m http.server 8000
# Откройте http://localhost:8000

# Windows
cd webm-export
python -m http.server 8000
# Откройте http://localhost:8000
```

**Решение 2:** Используйте другой браузер (Chrome/Firefox)

### Видео не скачивается

1. Проверьте папку "Загрузки"
2. Разрешите загрузки в настройках браузера
3. Проверьте консоль браузера (F12)

### Ошибка CORS

Откройте через локальный сервер (см. выше)

## 🔄 Ручной способ (если скрипт не работает)

```bash
# 1. Установите зависимости (один раз)
npm install

# 2. Соберите проект
npm run build

# 3. Создайте папку webm-export
mkdir -p webm-export

# 4. Скопируйте файлы
cp -r dist/* webm-export/

# 5. Откройте в Chrome
open webm-export/index.html
```
