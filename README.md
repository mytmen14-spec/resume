# Резюме за 40 секунд — Motion Graphics

Анимированное видео в формате 9:16 (вертикальное) о правилах создания эффективного резюме.

## 🚀 Быстрый старт

### Установка зависимостей

```bash
npm install
```

### Запуск в режиме разработки

```bash
npm run dev
```

Откройте браузер и перейдите по адресу, указанному в терминале (обычно http://localhost:5173)

### Сборка для продакшена

```bash
npm run build
```

Собранные файлы будут в папке `dist/`

## 🎥 Запись видео в WebM

### Способ 1: Через браузер (рекомендуется)

1. Запустите приложение: `npm run dev`
2. Откройте http://localhost:5173
3. Нажмите кнопку **"🎬 Записать видео"** в правом верхнем углу
4. Дождитесь окончания 40-секундной анимации
5. Файл `resume-motion-graphics.webm` скачается автоматически

### Способ 2: Через скрипт

```bash
npm run record
```

Этот скрипт автоматически откроет браузер, запустит запись и сохранит видео.

## 🎨 Технические детали

- **Формат**: 9:16 (вертикальное видео)
- **Длительность**: 40 секунд
- **Стиль**: Flat 2D vector animation
- **Цвета**: 
  - Красный акцент: `#E11D48`
  - Зелёный акцент: `#16A34A`
- **Шрифт**: Inter (sans-serif)

## 📋 Сцены видео

1. **0–5s**: Вступление с заголовком и резюме
2. **3–6s**: Три правила (карточки)
3. **6–16s**: Правило 1 — Одна должность
4. **16–26s**: Правило 2 — Цифры вместо обязанностей
5. **26–36s**: Правило 3 — Контакты сверху
6. **36–40s**: Финал с призывом к действию
