# 🎬 Резюме за 40 секунд — Motion Graphics

Анимированное видео в формате 9:16 о правилах создания эффективного резюме.

## 💾 Как сохранить видео в WebM (2 шага)

### 1. Откройте `dist/index.html` в Chrome

### 2. Нажмите «💾 Сохранить как WebM»

В появившемся окне выберите **«Эта вкладка»** → **«Поделиться»**. Через 40 секунд файл `resume-motion-graphics.webm` скачается автоматически.

**Подробная инструкция:** [SAVE-WEBM.md](SAVE-WEBM.md)

## 🚀 Разработка

```bash
npm install
npm run dev      # Запуск на http://localhost:5173
npm run build    # Сборка в папку dist/
```

## 📋 Сценарий видео

| Время | Сцена |
|-------|-------|
| 0–5s | Вступление |
| 3–6s | Три правила |
| 6–16s | Одна должность |
| 16–26s | Цифры вместо обязанностей |
| 26–36s | Контакты сверху |
| 36–40s | «ОТКЛИК БУДЕТ» |
