# 📦 Как скачать и сохранить проект

## Быстрый старт

### 1. Скачайте проект

**Вариант A: Через Git**
```bash
git clone <URL_РЕПОЗИТОРИЯ>
cd resume-motion-graphics
npm install
```

**Вариант B: Скачать ZIP**
- Нажмите "Code" → "Download ZIP" на GitHub
- Распакуйте архив
- Откройте терминал в папке проекта
- Выполните: `npm install`

### 2. Запустите проект

```bash
npm run dev
```

Откройте: http://localhost:5173

### 3. Запишите видео в WebM

1. Нажмите кнопку **"🎬 Записать видео"** в правом верхнем углу
2. Дождитесь окончания 40-секундной анимации
3. Файл `resume-motion-graphics.webm` автоматически скачается

## 🔧 Требования

- Node.js 16+
- npm 8+
- Chrome/Firefox/Edge (для записи видео)

## 🎥 Формат видео

- **Формат**: WebM (VP9)
- **Разрешение**: 375×667px (9:16)
- **Длительность**: 40 секунд
- **Качество**: 5 Mbps
- **FPS**: 30

## 🐛 Решение проблем

### Ошибка записи видео
- Убедитесь, что используете Chrome/Firefox/Edge
- Проверьте консоль браузера (F12)
- Разрешите доступ к медиа

### Низкое качество
- Откройте `scripts/VideoRecorder.ts`
- Увеличьте `videoBitsPerSecond` до 8000000

## 📞 Поддержка

Если возникли проблемы:
1. Проверьте `download/README.md`
2. Проверьте консоль браузера
3. Убедитесь, что все зависимости установлены
